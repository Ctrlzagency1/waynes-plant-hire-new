# Wayne's Plant Hire World: website concept

Static site, generated by `node build/build.mjs` (Node 22+, no dependencies). The generated HTML is committed, so Vercel serves the repo as-is.

- Source: `build/build.mjs` (templates), `build/fleet.mjs` (machines and types), `assets/css/wph.css`, `assets/js/app.js`
- Edit, run `node build/build.mjs`, commit, push. Vercel redeploys on every push.
- `vercel.json` sends `noindex` while this is a preview. Remove it at launch, and re-enable tracking (IDs in the comment in each page's head).

Live preview is deployed on Vercel from `main`.
